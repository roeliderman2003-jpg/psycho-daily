# מיפוי בחינות רשמיות של מאל״ו (מטא-דאטה בלבד)

האפליקציה מבוססת רק על הבחינות שמאל״ו פרסמו באתר שלהם. היא פותחת את ה-PDF המקורי מהאתר של מאל״ו, ומוסיפה טיימר, דף תשובות ומעקב. בשביל זה צריך מפה של כל בחינה: באיזה עמוד מתחיל כל פרק, ובאילו מספרי שאלות מופיע כל סוג שאלה.

## אסור (זכויות יוצרים — «אין להעתיק או להפיץ ללא אישור בכתב»)
- **לא מעתיקים** שאלות, תשובות, קטעי קריאה, נושאי חיבור או מפתח תשובות לשום קובץ. גם לא חלקים מהם.
- רושמים **רק מבנה**: מספרי עמודים, סוג פרק, מספר שאלות, טווחי מספרי שאלות לכל סוג, זמן.

## איך עובדים
1. מורידים כל PDF לתיקייה חדשה משלך בתוך ה-scratchpad (`curl -sL -A "Mozilla/5.0" <url> -o <file>`).
2. מייצרים תמונות של עמודים עם pymupdf: `python -I` ו-`pymupdf.open(f)[i].get_pixmap(dpi=60)`. הטקסט בקבצים מקודד בגופן שלא נקרא, ולכן צריך לקרוא מהתמונה. קודם מכינים דף מקדימה עם החלק העליון של כל העמודים (רצועה של 22% עליונים, 4 בשורה, מספר עמוד אדום), כדי לראות את המבנה. אחר כך פותחים ברזולוציה גבוהה יותר (dpi 90-110) רק את עמודי הפתיחה של הפרקים ואת הכותרות שמציינות טווחי שאלות, למשל «אנלוגיות (שאלות 1-6)», «קטע קריאה (שאלות 18-23)», «שאלות ובעיות (שאלות 1-8)», «הסקה מתרשים (שאלות 9-12)».
3. מספר עמוד = המספר בקובץ, החל מ-1 (לא המספר המודפס בדף). רושמים גם את המספר המודפס בעמוד הפתיחה של כל פרק, `printed`.
4. רושמים רק פרקי **חשיבה מילולית** ו**חשיבה כמותית**. פרקי אנגלית מדלגים, אבל רושמים ב-`skipped` כמה כאלה יש ובאילו עמודים.

## פורמט: מערך JSON בקובץ שלך `content/exams/<id>.json` (קובץ לכל בחינה)
```json
{
  "id": "winter_2025",
  "title": "חורף 2025",
  "url": "<הקישור המדויק שקיבלת>",
  "pages": 48,
  "english": false,
  "writing": { "page": 3, "printed": 2 },
  "chapters": [
    { "domain": "verbal", "label": "חשיבה מילולית – פרק ראשון", "page": 5, "printed": 4, "endPage": 12, "questions": 23, "minutes": 20,
      "sections": [ { "type": "analogy", "from": 1, "to": 6 }, { "type": "inference", "from": 7, "to": 17 }, { "type": "reading", "from": 18, "to": 23 } ] },
    { "domain": "quant", "label": "חשיבה כמותית – פרק ראשון", "page": 21, "printed": 20, "endPage": 28, "questions": 20, "minutes": 20,
      "sections": [ { "type": "problem", "from": 1, "to": 8 }, { "type": "chart", "from": 9, "to": 12 }, { "type": "problem", "from": 13, "to": 20 } ] }
  ],
  "formulasPage": 21,
  "answerSheetPages": [37, 39],
  "examplesPages": [40, 44],
  "keyPage": 45,
  "scorePages": [46, 48],
  "skipped": [ { "what": "אנגלית", "pages": [ ] } ],
  "notes": "רק דברים חריגים במבנה"
}
```
- `type`: `analogy` / `inference` / `reading` (במילולי), ו-`problem` / `chart` (בכמותי). אם כתוב «השלמת משפטים» או סוג אחר, רושמים `inference` ומוסיפים הערה ב-`notes`. אם יש שני קטעי קריאה, יש שני `sections` מסוג `reading`.
- `examplesPages`: העמודים עם חיבורים לדוגמה מוערכים (רמה גבוהה, בינונית, נמוכה), אם יש. אם אין, `null`.
- `scorePages`: עמודי «חישוב אומדן ציוני הבחינה», אם יש.
- `formulasPage`: עמוד דף הנוסחאות של הכמותי, אם יש.
- `questions` ו-`minutes`: כמו שכתוב בעמוד הפתיחה של הפרק («בפרק זה 23 שאלות. הזמן המוקצב הוא 20 דקות»).
- שדה שלא נמצא: `null`. **לא מנחשים.** אם משהו לא ברור, כותבים את זה ב-`notes`.

## בדיקה
- סכום טווחי ה-`sections` בכל פרק צריך לכסות בדיוק את 1 עד `questions`.
- `node -e "JSON.parse(require('fs').readFileSync('<file>','utf8'))"`.
- בסוף מוחקים את קובצי ה-PDF ואת התמונות שהורדת.

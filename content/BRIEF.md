# בריף לכתיבת פרקי תרגול — פסיכומטרי (המבנה החדש, דצמבר 2026)

המטרה: פרק ביום לנבחן שקיבל 620 בסימולציה הראשונה ורוצה לעלות לכ-700. כל פרק חייב להרגיש כמו פרק אמיתי של מאל״ו (לשעבר ניט״ל): אותו מבנה, אותם סוגי שאלות, אותה רמת קושי, קושי עולה בתוך כל קבוצה.

**חובה: תוכן מקורי בלבד.** לא להעתיק ולא לנסח מחדש שאלות מבחינות מאל״ו, מספרים או מאתרי הכנה. שאלות חדשות באותו סגנון.

## מבנה (מדצמבר 2026, בלי אנגלית)

### חשיבה מילולית — 23 שאלות, 20 דקות
- שאלות 1-6: **אנלוגיות** (`type: "analogy"`). צמד מילים מודגש, ו-4 צמדים לבחירה; בוחרים את הצמד שהיחס בין מילותיו הכי דומה ליחס בצמד המודגש. מילים בעברית תקנית, חלקן גבוהות (כמו בבחינה). קושי עולה: 1-2 קלות, 3-4 בינוניות, 5-6 קשות (יחס עדין, מילים נדירות).
- שאלות 7-17: **הבנה והסקה** (`type: "inference"`), תערובת:
  - `topic: "logic"` — שאלת היגיון: כמה עובדות/תנאים, מה בהכרח נכון / לא ייתכן / יכול להיות נכון (2-3 שאלות).
  - `topic: "short_text"` — פסקה קצרה (3-5 משפטים) ושאלה: מה אפשר להסיק, מה מחליש/מחזק את הטענה, מה ההנחה הסמויה, מה הפגם בטיעון (3-4 שאלות).
  - `topic: "meaning"` — משמעות של משפט/ביטוי/פתגם, איזה משפט אומר את אותו הדבר, או מה הקשר הלוגי בין שני משפטים (2-3 שאלות).
  - `topic: "sentence"` — השלמת משפט עם מילה/מילים חסרות (1-2 שאלות).
- שאלות 18-23: **הבנת הנקרא** (`type: "reading"`). קטע אחד של 4-6 פסקאות (כ-450-600 מילים, נושא עיוני: מדע, היסטוריה, חברה, אמנות, פילוסופיה). 6 שאלות: רעיון מרכזי, פרט בקטע, תפקיד פסקה/משפט, הסקה, משמעות מילה בהקשר, עמדת הכותב. הפסקאות ממוספרות, ואפשר להפנות אליהן ("בפסקה השלישית").

### חשיבה כמותית — 20 שאלות, 20 דקות
- שאלות 1-8: **שאלות ובעיות** (`type: "problem"`), קושי עולה (1-3 קלות, 4-6 בינוניות, 7-8 בינוניות-קשות).
- שאלות 9-13: **הסקה מתרשים** (`type: "chart"`). תרשים אחד או טבלה אחת (stim), ו-5 שאלות עליו. קושי עולה.
- שאלות 14-20: **שאלות ובעיות** (`type: "problem"`), קושי עולה עד קשות מאוד.
- נושאים (`topic`), לפזר כך שכל פרק נוגע ב-8+ נושאים שונים: `algebra` (משוואות, ביטויים, אי-שוויונים), `percent` (אחוזים, יחסים, פרופורציה), `word` (בעיות מילוליות: תנועה, הספק, גילים, תערובות, קנייה), `averages` (ממוצעים), `integers` (מספרים שלמים, זוגיות, חלוקה, ראשוניים, מחלקים), `powers` (חזקות ושורשים), `geometry` (זוויות, משולשים, מרובעים, מעגלים, שטחים והיקפים), `solids` (גופים: תיבה, קובייה, גליל, נפח, שטח פנים), `coordinates` (מערכת צירים, ישרים), `probability` (הסתברות וקומבינטוריקה), `sequences` (סדרות ודפוסים), `defined_ops` (פעולות מוגדרות/סימנים חדשים), `functions`, `chart` (לשאלות התרשים).
- לפחות 2 שאלות בכל פרק בלי תשובה מספרית ישירה (השוואה בין ביטויים, "איזה מהבאים בהכרח נכון" על פרמטרים).
- שאלות גאומטריה: לפחות 3 בכל פרק עם שרטוט (`fig`). כמו בבחינה: "השרטוט אינו בהכרח בקנה מידה".

## רמת קושי
כמו בבחינה האמיתית: הבחינה מחולקת בערך שווה בין קלות, בינוניות וקשות. בכל קבוצה הקושי עולה. השאלות האחרונות בכמותי צריכות להיות באמת קשות (ציון 700+), אבל פתירות בכ-1.5-2 דקות למי שמכיר את הטריק. מסיחים (תשובות שגויות) חייבים להיות סבירים: התוצאה של טעות נפוצה, לא מספרים אקראיים.

## הסברים (הכי חשוב: מהם הוא לומד)
לכל שאלה:
- `explain`: פתרון מלא, צעד אחר צעד, בעברית ברורה ופשוטה, 3-8 משפטים. בכמותי: כל חישוב מופיע. במילולי: למה התשובה הנכונה עונה בדיוק על מה שנשאל.
- `fast`: הדרך המהירה בבחינה (הצבת מספרים, בדיקת תשובות מהסוף, פסילה, הערכה, זיהוי היחס). משפט-שניים. אם אין דרך מהירה יותר, דרך לבדוק את התשובה.
- `traps`: מערך של 4 מחרוזות, אחת לכל תשובה (באותו סדר). לתשובה הנכונה: "". לשגויות: למה היא שגויה / איזו טעות מובילה אליה (משפט אחד קצר).
- `skill`: שם המיומנות בשתיים-שלוש מילים (למשל "יחס חלק-שלם", "תנועה נגדית", "שלילת טענה", "משולש ישר-זווית 30-60-90"). משמש לפילוח חוזקות וחולשות.

## בדיקת נכונות (חובה לפני שמסיימים)
- **כמותי:** פתור כל שאלה מחדש, בנפרד מהכתיבה, בקוד (python דרך Bash). ודא שבדיוק תשובה אחת נכונה ושהמסיחים שגויים. שאלות התרשים: חשב מהנתונים שבתרשים עצמו. שרטוט: ודא שהמספרים שבו תואמים לשאלה.
- **מילולי:** ודא שבכל שאלה יש תשובה אחת שהיא בבירור הטובה ביותר, ושאין מסיח שאפשר להגן עליו באותה מידה. באנלוגיות: נסח את היחס במשפט ("X הוא כלי שבו עושים Y") ובדוק אותו על כל 4 התשובות.
- פיזור התשובות הנכונות: בערך שווה בין 1-4 בכל פרק, בלי יותר מ-3 ברצף אותו מספר.

## פורמט הקובץ
קובץ JSON תקין אחד לכל פרק: `content/src/<id>.json` (UTF-8). מזהים: `v01`-`v99` מילולי, `q01`-`q99` כמותי.

```json
{
  "id": "q03",
  "domain": "quant",
  "title": "כמותי 3",
  "minutes": 20,
  "stims": {
    "c1": {
      "kind": "chart",
      "intro": "בתרשים שלפניך מוצג ... (טקסט ההסבר שמופיע מעל התרשים בבחינה)",
      "html": "<svg ...>...</svg> או <table class=\"dt\">...</table>"
    }
  },
  "questions": [
    {
      "n": 1,
      "type": "problem",
      "topic": "percent",
      "skill": "הנחה כפולה",
      "level": 1,
      "stim": null,
      "stem": "מחיר מוצר ירד ב-20% ואחר כך עלה ב-20%. ...",
      "fig": null,
      "options": ["...", "...", "...", "..."],
      "answer": 3,
      "explain": "...",
      "fast": "...",
      "traps": ["...", "...", "", "..."]
    }
  ]
}
```

- `answer`: 1-4 (מספר התשובה הנכונה).
- `level`: 1 קלה, 2 בינונית, 3 קשה.
- `stim`: מזהה מ-`stims` כששאלה שייכת לקטע/תרשים, אחרת null. במילולי, קטע הקריאה: `"kind": "passage"`, `"title"`, `"paras": ["פסקה 1", ...]` (בלי html).
- `stem`, `options`, `explain`, `fast`, `traps`: טקסט. מותר HTML פשוט בלבד: `<b>`, `<i>`, `<sup>`, `<sub>`, `<br>`, `<span class="ltr">` לביטויים מתמטיים שצריך להציג משמאל לימין (למשל `<span class="ltr">x² + 3x = 10</span>`). שורשים: `√`. שברים: `3/4` או `<span class="fr"><i>3</i><i>4</i></span>` (מונה, מכנה).
- אנלוגיה: `stem` = הצמד המודגש בפורמט `"<b>מילה1 : מילה2</b>"`, ו-`options` = 4 צמדים בפורמט `"מילה : מילה"`.
- `fig` / `html` של תרשים: SVG בתוך המחרוזת. כללים: `viewBox` בלי width/height קבועים, `stroke="currentColor"` ו-`fill="none"` לקווים, טקסט עם `fill="currentColor"`, `font-size` 13-16, `font-family="Rubik, sans-serif"`. רוחב viewBox עד 360. לא להשתמש בצבעים קבועים חוץ מ-`#1cb0f6` (כחול) ו-`#ff9600` (כתום) לסדרות בתרשים. אותיות של קודקודים באנגלית (A, B, C) כמו בבחינה.
- טבלה: `<table class="dt"><tr><th>..</th></tr>...</table>`.
- בלי שורות חדשות בתוך מחרוזות JSON (להשתמש ב-`<br>`), בלי מרכאות כפולות לא מוברחות. בעברית להשתמש ב-״ (גרשיים) ולא ב-" בתוך טקסט.

## בסוף

2. דווח בקצרה: אילו קבצים נכתבו, פיזור התשובות, ואילו שאלות תיקנת בבדיקה.

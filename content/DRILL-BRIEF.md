# בריף לתרגול לפי נושא

תרגול ממוקד לנושא אחד, לנבחן שרוצה לעלות מ-620 לכ-700 בפסיכומטרי הדו-תחומי (דצמבר 2026). הנבחן פותר שאלה אחת בכל פעם, ומקבל מיד את הפתרון.

**קודם קוראים את `content/BRIEF.md`.** כללי השאלות, ההסברים, הבדיקה והפורמט של שאלה בודדת זהים לשם: `explain`, `fast`, `traps`, `skill`, `level`, `stim`, `fig` וכללי ה-SVG. כמו שם, רק תוכן מקורי.

## מה שונה כאן
- **קובץ אחד לכל נושא:** `content/drills/<id>.json`.
- **סדר השאלות:** בכל נושא הקושי עולה בהדרגה. בערך שליש קלות, שליש בינוניות ושליש קשות, ברמת הבחינה האמיתית. כל שאלה מתרגלת `skill` אחר בתוך הנושא, ומכסה את כל סוגי השאלות שמופיעים בבחינה בנושא הזה.
- **`guide` (הכי חשוב):** «מה חשוב לדעת» על הנושא. 6-10 נקודות קצרות: הכללים, הנוסחאות, הטריקים והמלכודות הנפוצות. כל נקודה משפט-שניים, עם דוגמה קצרה כשאפשר. זה דף הלימוד של הנושא, ולכן הוא צריך להיות מדויק, פרקטי ומכוון בחינה. מותר HTML פשוט כמו בבריף (`<b>`, `<span class="ltr">`, `<sup>`).
- `explain` של כל שאלה מפנה לכלל הרלוונטי ב-`guide` כשזה מתאים («לפי כלל ההכרחי והמספיק…»).

## פורמט
```json
{
  "id": "percent",
  "domain": "quant",
  "title": "אחוזים, יחסים ופרופורציה",
  "guide": ["...", "..."],
  "stims": {},
  "questions": [ { "type": "problem", "topic": "percent", "skill": "...", "level": 1, "stim": null, "stem": "...", "fig": null, "options": ["","","",""], "answer": 2, "explain": "...", "fast": "...", "traps": ["","","",""] } ]
}
```
- `type` לפי סוג השאלה בבחינה: `analogy` / `inference` / `reading` / `problem` / `chart`.
- `topic` = ה-id של הקובץ.
- פיזור התשובות הנכונות: בערך שווה, ובלי יותר מ-2 ברצף.

## בדיקה (חובה)
- **כמותי:** כל שאלה נפתרת מחדש ב-python. בדיוק תשובה אחת נכונה.
- **מילולי:** בכל שאלה יש תשובה אחת שהיא בבירור הטובה ביותר. שאלות היגיון נבדקות בכל הצירופים בקוד.
- **`guide`:** כל כלל ונוסחה נבדקים, כי טעות בדף הלימוד מזיקה יותר מטעות בשאלה.
- **טעינה:** `node -e "const d=require('<path>'); console.log(d.questions.length, d.guide.length)"`.
- סקריפטים שומרים רק בתיקייה של הסוכן בתוך ה-scratchpad. סוכנים אחרים עובדים במקביל. אם בודקים שרטוט בדפדפן, עושים את זה בטאב חדש ובפורט משלך, וסוגרים בסוף.
- לא מריצים `build.js` ולא נוגעים בקבצים של אחרים.

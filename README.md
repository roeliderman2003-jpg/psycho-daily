# פרק ביום — פסיכומטרי

תרגול לבחינה הפסיכומטרית הדו-תחומית (מדצמבר 2026), **רק מהחומרים הרשמיים של מאל״ו**. האפליקציה לא מכילה שאלות: היא פותחת את קובצי הבחינות שמאל״ו פרסמו באתר שלהם, ומוסיפה טיימר בזמן של הבחינה, דף תשובות, בדיקה מול מפתח התשובות הרשמי (שמקלידים מהקובץ), פילוח חוזקות לפי סוג שאלה, תרגול טעויות ומטלות כתיבה רשמיות.

- מפות הבחינות (רק עמודים, פרקים וטווחי סוגי שאלות): `content/exams/*.json`. איך ממפים: `content/EXAMS-BRIEF.md`. אחרי שינוי: `node build.js`.
- ההתקדמות נשמרת בדפדפן (localStorage), עם קוד גיבוי בהגדרות.
- אתר סטטי, GitHub Pages מ-main. לא קשור למאל״ו.

## מפתחות והסברים
- המפתח הרשמי והסבר לכל שאלה נמצאים ב-`content/solutions/<id>.json`, **מחוץ ל-git** (הבחינות של מאל״ו אסורות בהפצה). איך כותבים אותם: `content/SOLUTIONS-BRIEF.md`.
- `node seal.js` מצפין אותם ל-`sol.js` (AES-GCM, קוד הגישה ב-`.secret`, גם הוא מחוץ ל-git). באתר יש רק העותק המוצפן.
- האפליקציה נפתחת פעם אחת בכל מכשיר עם הקישור `.../psycho-daily/#k=<קוד>`, והקוד נשמר במכשיר.

## מילים (לשונית 🔤)
- `python vocab.py` מחלץ מקובצי מאל״ו את כל שאלות האנלוגיה (240 שאלות, 1,200 זוגות) ל-`content/words/analogies.json`, ומצרף לכל מילה את הפירוש מ-`content/words/meanings.json` (שכתבנו: רמה 0 קלה / 1 לוודא / 2 קשה, פירוש, דוגמה, מובן נוסף). מילים ברמה 1-2 נכנסות ל-`content/words/words.json`, לפי סדר: כמה בחינות הופיעה, קושי, ומהבחינה החדשה.
- `node seal.js` מצפין את המאגר לתוך `sol.js` (`_voc`). הכל ב-`content/words/` מחוץ ל-git.
- באפליקציה: שיעור (10 חדשות + חזרה מרווחת אחרי 1/2/4/8/16/32 ימים), מיון מהיר של מה שכבר מכירים, חזרה, טעיתי, כרטיסיות עם 3 דירוגים, ומילון עם חיפוש. ההתקדמות ב-`S.voc`, נשמרת בענן וממוזגת לפי מילה.

# פרק ביום — פסיכומטרי

תרגול יומי לבחינה הפסיכומטרית הדו-תחומית (מדצמבר 2026): פרק מילולי (23 שאלות) או כמותי (20 שאלות) בזמן אמת של 20 דקות, ציון, פתרון מפורט לכל שאלה, פילוח חוזקות וחולשות ותרגול טעויות. לשונית «רשמי» פותחת בחינות של מאל״ו מהאתר שלהם עם טיימר ודף תשובות.

- הפרקים: `content/src/*.json` (הבריף לכתיבה: `content/BRIEF.md`). אחרי שינוי: `node build.js` בונה את `chapters.js` ובודק תקינות.
- ההתקדמות נשמרת בדפדפן (localStorage), עם קוד גיבוי בהגדרות.
- אתר סטטי, GitHub Pages מ-main.

השאלות מקוריות. לא קשור למאל״ו.
